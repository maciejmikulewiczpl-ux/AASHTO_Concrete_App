# Excel Batch Runner Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macro-enabled Excel template whose Run button sends every row (section × load case) to a bundled engine exe, which runs the app's engine, writes results back and saves an `.aashto.json` project.

**Architecture:** A new Python package `batch/` with these modules:
- `form.py`: field model and UI defaults.
- `inputs.py`: a Python port of `gatherInputs()`.
- `project.py`: section state and project file.
- `sheet_io.py`: TSV exchange, grouping and validation.
- `columns.py`: the input, settings and result column specs.
- `runner.py`: the run loop.

`batch_runner.py` is the CLI, frozen to `AASHTO_Batch.exe` with PyInstaller. Excel ↔ exe exchange uses tab-separated text files next to the workbook (Excel locks the open `.xlsm`):
- Inputs: the VBA macro writes `_batch_inputs.tsv` and `_batch_settings.tsv`.
- Results: the exe writes `_batch_results.tsv` and `_batch_progress.txt`.
- The macro imports the results.

The template `.xlsm` is generated by a PowerShell script through Excel COM from a JSON dump of `batch/columns.py`, so column order has one source.

**Tech Stack:** Python 3.12 stdlib only in `batch/` (csv, json, math), existing `calc_engine` / `mphi_engine`, PyInstaller 6.20.0, VBA (Excel 16), PowerShell 5.1 COM, node (tests only, parity harness).

**Spec:** `docs/superpowers/specs/2026-11-21-excel-batch-design.md`

## Global Constraints

- Results must equal the app's: same raw-input dict as `gatherInputs()` (index.html ~4436), same engine calls.
- Do not modify `calc_engine.py`, `circ_engine.py` or `mphi_engine.py`. `tests/test_rect_i_unchanged.py` stays green with no regeneration.
- No Al_tors / Al_min / Al_gov keys and no Eq. 5.7.3.6.3-2 or "-3" anywhere (CLAUDE.md); torsion longitudinal output is `long_comb_ok` / `long_dem_comb` / `long_cap_val` only.
- No new AASHTO citation strings in headers; reuse wording already in the app.
- Notify the user before each edit of `index.html` / `api.py` (CLAUDE.md). Never delete > 5 lines from `index.html`, `calc_engine.py` or `api.py`.
- v1 scope: RECTANGULAR, T-SECTION, CIRCULAR; BEAM / SLAB; no prestress, no multi-row rebar (`mrData` null), no d / Ec / fpy / εcl / εtl overrides.
- Units: the sheet uses one of the app's four display-unit combinations (force kip|lbf × length in|ft); convert with the app's `unitFactor` rules. Bar spacing in spacing mode is **always inches** (app behaviour, index.html ~8558).
- Users need no Python: everything the button needs ships in `AASHTO_Batch.exe` + the `.xlsm`.
- `python run_test_suite.py --full` all stages PASS, plus `pytest tests/ -q`, before claiming done.

## Review Focus

1. **Comma-decimal Windows locale** (Polish / German Excel): numbers must cross VBA ↔ TSV with "." regardless of locale. Pinned in Task 7 (static VBA test: numeric export via `Str`, import via `Val`, never `CStr`/`CDbl` on numbers) and Task 4 (parser rejects "1,5" with a clear row error rather than misreading it).
2. **Blank and ragged rows:** fully blank rows (including trailing formatted rows) are skipped. A row with a Section ID but missing required cells → ERROR for that section naming the column. Pinned in Task 4.
3. **Non-contiguous IDs:** rows of one Section ID separated by other sections still group together, in first-appearance order. Results are written back in the original row order. Pinned in Task 4 and Task 5.
4. **One failing section** (engine exception, M–φ "not available", axial over capacity) gives ERROR / note on that section's rows only, and the other sections still run. Pinned in Task 5.
5. **Workbook path with spaces or non-ASCII characters** passed to the exe: quoted in VBA, and the CLI is tested with such a path. Pinned in Task 6 and Task 7.

### Task 5: Run loop and results

**Files:**
- Create: `batch/runner.py`
- Modify: `batch/columns.py` (add `RESULT_COLUMNS`)
- Test: `tests/test_batch_runner.py`

**Interfaces:**
- Consumes: Tasks 2-4. Calls `calc_engine.calculate_all(inputs, demand_rows, i)` once per demand row (row i active) and `mphi_engine.moment_curvature_section(inputs, Ms=row["Ms"], Ps=row["Ps"], model=…, expected_concrete=…, expected_steel=…)` per row.
- Produces:
  - `run_batch(inputs_tsv: str, settings_tsv: str, results_tsv: str, progress_path: str | None = None) -> dict`: returns `{"sections": n, "rows": n, "errors": n, "project": path | None}`.
  - Writes `results_tsv` with one line per **input** row in the original order, and blank rows for blank input rows, so the macro can paste the block 1:1.
  - The progress file holds `"k/n <section id>"`, rewritten per section.
  - It also writes the project file (Task 3).
- `RESULT_COLUMNS: list[RCol]` with `RCol(header, source, kind)`. `source` is a dotted path into a per-row context `{"res": calculate_all result, "row": row_results[i], "mphi": mphi result, "calc": batch-computed}`. `kind` is used to convert to display units. Columns:
  - **Status:** `calc.status` (OK | NG | ERROR) and `calc.message`. NG = any of flexure, shear or torsion D/C > 1, or `row.flexStatus` / `row.crackStatus` not passing.
  - **Flexure:**
    - `row.Mr` (abs), `res.flexure.Mn`, `res.flexure.phi_f`, `res.flexure.c`, `res.flexure.a`, `res.flexure.ds`, `res.flexure.dt`, `res.flexure.eps_t`, `res.flexure.As`, `res.flexure.Mcr`, `res.flexure.min_flex_ok`, `res.flexure.Mr_atPu`
    - `calc.dc_M = |Mu|/|Mr|` (0/0 → blank, Mr = 0 → "inf"; the same rules as `setDC`, index.html ~3000)
    - `row.flexStatus`
  - **Shear:**
    - `calc.shear_method`
    - `calc.Vr` = `row.Vr1` | `row.Vr2` | `row.Vr3` for simp | gp | b5 (`setDCShear`, index.html ~3043)
    - `row.Vr1`, `row.Vr2`, `row.Vr3`, `res.shear.dv`, `res.shear.bv`
    - `calc.beta` / `calc.theta` / `calc.Vc` / `calc.Vs` = `res.shear.bt{k}` / `th{k}` / `Vc{k}` / `Vs{k}` with k = 1 | 2 | 3 by method
    - `res.shear.eps_s`, `res.shear.Vnmax`, `res.shear.Av_min`, `res.shear.has_min_av`, `res.shear.s_max_sh`
    - `calc.dc_V`, `row.long_dc_{k}`, `row.long_ok_{k}`, `row.shearStatus`
  - **Torsion:**
    - `res.torsion.consider`, `res.torsion.Tcr`, `res.torsion.thresh`, `res.torsion.Tr`, `res.torsion.At_s_design`
    - `res.torsion.long_comb_ok`, `res.torsion.long_dem_comb`, `res.torsion.long_cap_val`
    - `calc.dc_T = |Tu|/Tr`
  - **Crack / service:** `res.flexure.fss_used`, `res.flexure.s_crack`, `res.flexure.s_crack_actual`, `row.crackStatus`, `res.flexure.Icr`, `res.flexure.Ieff`, `res.flexure.Ig`.
  - **Moment–curvature:**
    - `mphi.model`
    - `mphi.service.Ieff` and `calc.mphi_Ieff_Ig_service`, `mphi.service.EI`
    - `mphi.first_yield.M`, `mphi.first_yield.phi`, `mphi.idealised.Mp`, `mphi.idealised.phi_y`, `mphi.idealised.EI`

    - `calc.mphi_note`: `reason`, `service_error` or notes joined with "; "
