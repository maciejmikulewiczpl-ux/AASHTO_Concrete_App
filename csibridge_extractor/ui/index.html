How to use
  1. In CSiBridge: open the model, run the analysis, and close every dialog (CSiBridge does not answer while a dialog is open).
  2. Connection: pick the model in the list (Refresh if you just opened it) and click Connect.
  3. Targets: pick one or more groups, and/or type frame / joint labels or ranges (e.g. 1201-1210). A group alone is enough: its frames go to Frame forces, its joints to Joint reactions and Joint displacements.
  4. Cases: tick the load cases / combinations. Greyed ones have no results (not analysed).
  5. Tables: choose Envelope, Correspondence or Both. Joint reactions and joint displacements (U1-U3, R1-R3) are off by default.
  6. Output: leave the folder empty to save next to the model file. Choose Excel, or CSV for big extractions (much faster; one file per table, ready for Power Query: Data > Get Data > From Folder). Then click Run.
  • Fastest: one CSiBridge group that holds everything you need (about a second). Objects not in one group make it read the whole model (can take minutes).
  • Values are written exactly as CSiBridge gives them, in the model's units (shown in row 2 of each tab). Check the Run info tab for warnings.
  • Linking other spreadsheets (Power Query): tick Overwrite so every run replaces the same file / folder; save the job and re-run it after each analysis, then Refresh in Excel.
  • Save job / Load job repeats the same extraction later. The model is never changed or saved.
